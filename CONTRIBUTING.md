# Contributing

Thank you for helping improve Personal AI Agent.

1. Open an issue for substantial behavior or data-model changes.
2. Keep pull requests focused and explain the user problem they solve.
3. Add or update a behavior test when changing initialization, validation, path handling, or privacy boundaries.
4. Run `python -m unittest discover -s tests -v`.
5. Use examples and synthetic data only. Never submit personal records, conversations, credentials, payment data, or machine-specific paths.
