# Code of conduct

Be respectful, specific, and constructive. Welcome people with different backgrounds and levels of experience. Disagreement about design is normal; harassment, personal attacks, discrimination, doxxing, and publishing another person's private data are not acceptable.

Maintainers may edit or remove abusive content and restrict participation when needed. Report conduct concerns through GitHub's private vulnerability reporting form (Security tab → Report a vulnerability) or by contacting the maintainer through their GitHub profile, rather than posting sensitive details publicly.
