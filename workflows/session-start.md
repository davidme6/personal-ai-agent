# 开工

1. 读 `AGENTS.md`。
2. 私有仓模式下先 `python tools/sync.py pull`，拿到别的设备和 AI 留下的最新状态。
3. 读 `.personal/profile.md`、`.personal/current-state.md`、`.personal/memory/open-loops.md`。
4. 按 `.personal/project-registry.json` 找到本次相关的项目，读它的入口和状态；更深的证据按需再读。
5. 说清楚：哪些已确认、哪些还不确定、这次要做什么。

历史记录只说明当时的状态，不等于授权继续做没做完的事。
