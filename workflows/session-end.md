# 收尾

用户说“结束 / 归档 / 收尾 / 今天到这”时做：

1. **对话原文**：跑 `python tools/refresh.py`。它导出本机所有 AI 的逐字对话、建语义索引、生成总索引、列出超过 30 天没核实的记忆段落。网页版 AI 没有本机会话文件，就由它逐轮写下原文，拿不到的轮次标【原文不可取得】。
2. **工作日志**：把这次做了什么、为什么、怎么验证的、哪些没验证，写进 `.personal/logs/work-logs/`（模板 `templates/work-log.md`）。
3. **未闭环事项**：新出现的、状态变了的，更新到 `.personal/memory/open-loops.md`（status / 下一步 / 卡点 / source）。
4. **长期记忆**：本轮出现的稳定新事实（新定的规矩、偏好变化、技术决定）追加到 `.personal/memory/`，写日期，不覆盖旧的。原始聊天不直接当成已核实的知识。
5. **精确事实回原文**：涉及日期、数字、原话的，打开 `.personal/logs/chat-exports/` 核对。
6. **当前状态**：更新 `.personal/current-state.md`，只改自己这部分，不抹掉别人的。需要换窗口或换设备的，另写一份 `.personal/handoff/YYYY-MM-DD.md`。
7. **上传**：用户说的是“归档本地云端”才提交推送（`sync.py push`），否则告诉用户还有哪些没上传。
8. 汇报：做完了什么、怎么核对的、还有哪些要另一台设备或外部服务才能确认。
