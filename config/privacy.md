# 隐私模型

框架和你的数据各管各的。

| 数据 | 默认位置 | Git | 云盘 / 文件同步 |
|---|---|---|---|
| 框架、模板、工具 | 仓库根目录 | 可以 | 可以 |
| 状态、记忆、项目记录、逐字对话、日志 | `.personal/` | 公开模板里排除；私有仓模式下只进**你的私有仓** | 不必 |
| 原件资料 | `.personal/files/` | 排除 | 你自己的飞书云空间 / 云盘 |
| 隐私文件 | `.personal/private/` | 排除 | 不同步，另做加密备份 |
| 本机路径和凭据 | `.device/` | 排除 | 不要明文同步 |
| 索引、缓存、全量会话备份 | `.local/` | 排除 | 不同步 |

## 安全阀做了什么

- `pre-push`：只许推到 `.personal/agent.json` 里的 `private_remote`；没设就一律不推。
- `pre-commit`：查密钥格式和明文密钥赋值、带校验位的身份证号、隐私目录、原件目录、超过 100MB 的文件、嵌套仓库；手机号只提示。读的是暂存区里的内容。
- 远端是不是私有仓：`pre-push` 和 `upload_check.py --all` 会让 `gh` 查一次（没装或没登录只提示，不拦）；每次提交不联网。
- 导出对话时，明显的密钥格式（如 `sk-…`、`ghp_…`）会被打码。

## 几条要记住的

- Git 历史很难撤回。后来加的 `.gitignore` 规则不会把旧提交里的秘密删掉。
- 私有仓也是上传：只放你愿意放在那家服务上的东西。
- 同步不是备份：它可能把删除、损坏或冲突也传过去。另在别的设备、离线介质或本机加密后的云端归档里留一份能恢复的副本。
- 公开你自己的 fork 之前，同时检查当前文件和全部 Git 历史。永远不要拿真实的个人工作区当公开仓的历史起点。

## 私有仓里会带上哪些本机标识

你自己的私有仓里（不是公开模板）会出现这些，属于你自己的数据，但分享仓库前要知道：

- **设备名**：默认取主机名，会出现在导出对话的文件名、文件头和 `.personal/logs/trace/<设备名>/` 目录里。不想用真实主机名，在 `.device/device.json` 里改 `device_name`。
- **项目目录**：导出对话的文件头会记当时的工作目录（可能含系统用户名）。
- **飞书账号信息**：`.personal/feishu-map.json` 记着确认过的飞书账号和应用标识，用来防止定时任务写错账号；它在默认的自动同步路径里，会随私有仓到达其他设备。
